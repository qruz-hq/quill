# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism about the work
and not the person. Harassment, insults and discrimination are not accepted in
issues, pull requests or any other project space.

To report a problem, contact the maintainer privately through the
repository's **Security** tab, under **Report a vulnerability**, and say it is
a conduct report. Reports are kept confidential.
